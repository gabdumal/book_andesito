Distros Linux

Neste guia, apresentamos exemplos de configuração de vários programas em duas distros: o Fedora Linux, e o Linux Mint. Vamos analisar algumas características principais de cada e cobrir suas instalações.

Antes de discorrermos sobre os dois sistemas, precisamos entender o que é necessário para instalar qualquer um deles.

Primeiro, você precisará de um pen-drive com pelo menos 4GB de armazenamento. Os dados desse pen-drive serão apagados para fazer a instalação do sistema, então, antes de prosseguir, faça um backup dos arquivos e pastas dentro dele em um lugar seguro (como algum serviço de armazenamento em nuvem).

Quando você transferir a distro para esse pen-drive, ele funcionará como um flash-drive bootável (também chamado de Live USB). Isso significa que você poderá conectá-lo no seu computador e iniciar a distro transferida por meio dele, durante o processo de ligar o computador. Não se preocupe: depois da instalação, você pode facilmente transformar o pen-drive de volta em um flash-drive de arquivos.

Outra recomendação é que você faça um backup dos arquivos do seu computador em um serviço de armazenamento em nuvem. Embora seja possível instalar uma distro Linux ao lado de um sistema operacional já instalado, esse processo é mais complexo e você pode acabar cometendo algum erro na sua primeira tentativa.

Minha sugestão é que você faça um backup de tudo o que achar necessário. Esteja seguro de que você pode remover o sistema operacional atual do computador completamente, junto com todos os arquivos. Então, após removê-lo, você poderá criar os espaços para instalar dois sistemas operacionais um do lado do outro (como uma distro Linux e o Windows 11, por exemplo). Esse tipo de instalação é chamado de dual boot.

Com último comentário: várias distros Linux permitem que você faça a encriptação do seu dispositivo de armazenamento (HD ou SSD). Isso pode ser interessante para garantir que ninguém tenha acesso aos seus arquivos caso você perca seu laptop. Contudo, essa configuração exige alguns passos mais complexos. Por isso, recomendo que você não se preocupe com encriptação na sua primeira instalação do Linux.

Fedora Linux

Seção intitulada “Fedora Linux”

Fedora Linux é uma distro Linux mantida por uma comunidade independente de desenvolvedores com apoio direto da empresa Red Hat — atualmente subsidiária da IBM.

O Projeto Fedora busca oferecer um conjunto de software por cima do kernel Linux que forneça tecnologias modernas. Muitas vezes, ele adota padrões recentes, mesmo quando ainda restam alguns poucos aprimoramentos a serem testados em casos específicos.

Por exemplo, o Fedora apoia a adoção do protocolo gráfico Wayland nos principais ambientes de área de trabalho suportados. Isso permite que computadores mais recentes utilizem todas as suas potencialidades (como HDR, e monitores com resoluções diferentes).

Contudo, se você necessitar de alguma função que não foi completamente implementada no Wayland, pode ser mais interessante utilizar uma outra distro, com uma filosofia de atualização menos recente. Essa mesma lógica se aplica para outros contextos.

O Projeto Fedora recebe recursos de corporações como a Red Hat, mas mantém autonomia sobre suas decisões. A ideia é que os usuários do Fedora possam utilizar um sistema novo e polido. Ao mesmo tempo, as contribuições da comunidade que se consolidam são adotadas em distros mais estáveis, como a Red Hat Enterprise Linux mais tarde.

Linux Mint

Seção intitulada “Linux Mint”

Linux Mint é uma distro Linux mantida por uma comunidade independente de desenvolvedores. Ele recebe apoio de recursos de algumas corporações, mas em proporção menos expressiva que o Fedora Linux.

O Linux Mint é — em sua versão principal — baseado na distro Ubuntu, que foi conhecida por muito tempo como uma das mais simples de utilizar. O objetivo do Mint é fornecer as facilidades do Ubuntu, mas com uma interface gráfica mais tradicional, e com a adoção de tecnologias mais estabilizadas no ecossistema Linux.
