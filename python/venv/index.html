Ambientes virtuais

Uma das características fundamentais do Python é a facilidade de que dispõe para instalar pacotes utilitários. Para que diferentes projetos nos nossos computadores não tenham conflitos de versões, é recomendado criar um ambiente virtual para cada um.

Existem várias ferramentas que fazem isso. Neste guia, usaremos o venv. Ele é um módulo padrão do Python, que cria uma pasta isolada dentro de um projeto. Então, podemos usar o pip para instalar as dependências dentro dessa pasta.

Escolha uma das formas abaixo e a siga. Caso queira seguir uma e depois a outra, basta apagar a pasta .venv criada ao fim do processo.

Visual Studio Code

Seção intitulada “Visual Studio Code”

Abra a Command Palette com o atalho Control + Shift + PCtrlShiftPControl + Shift + PCtrlShiftP, e digite Python: Create Environment.

Então, selecione a ferramenta venv no menu que se abrir.

Em seguida, selecione o caminho do interpretador como /bin/python.

O ambiente virtual será criado em uma pasta chamada .venv. No rodapé do Visual Studio Code, você poderá ver a versão do Python usada e o ambiente do venv selecionado.
