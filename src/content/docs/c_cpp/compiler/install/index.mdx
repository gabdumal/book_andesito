Nesta seção, vamos instalar as ferramentas de compilação para C e C++ para o Fedora, para o WSL usando o Fedora e para o Mint, além de outros derivados do Debian compatíveis.

Instalaremos os pacotes do [**LLVM**](https://www.llvm.org/), que é um projeto focado em desenvolver diversas ferramentas de compilação, incluindo o compilador [**Clang**](https://clang.llvm.org/).
Também instalaremos o [**Ninja**](https://ninja-build.org/), um gerador de build com foco em velocidade.

## Fedora e WSL

Para obter as ferramentas no Fedora ou no WSL usando o Fedora, vamos instalar os pacotes listados oficialmente pelo Fedora para o projeto [LLVM](https://packages.fedoraproject.org/pkgs/llvm/) e para o [Ninja](https://packages.fedoraproject.org/pkgs/ninja-build/).
**Execute** os seguintes comandos no terminal.

```zsh title="Fedora ou WSL" frame="terminal"
sudo dnf upgrade -y

# Libraries
sudo dnf install -y \
  glibc-devel \
  libcxx-devel \
  libcxxabi-devel

# Compiling
sudo dnf install -y \
  clang \
  compiler-rt \
  lld \
  lldb \
  llvm \
  ninja-build

# Tools
sudo dnf install -y \
  clang-analyzer \
  clang-tools-extra \
  clangd \
  git-clang-format
```

Você pode **verificar** a instalação com os comandos abaixo.
As versões instaladas devem ser iguais ou superiores às listadas.

```zsh title="Fedora ou WSL" frame="terminal"
clang --version
# clang version 22.1.5 (Fedora 22.1.5-1.fc44)
# Target: x86_64-redhat-linux-gnu
# Thread model: posix
# InstalledDir: /usr/bin
# Configuration file: /etc/clang/x86_64-redhat-linux-gnu-clang.cfg

ninja --version
# 1.13.2
```

## Mint

Para instalar as ferramentas no Mint ou em outras distribuições baseadas no Debian, **execute** os seguintes comandos no terminal:

```zsh title="Mint" frame="terminal"
sudo apt update -y && sudo apt upgrade -y

## Libraries
sudo apt install -y \
    libc++-dev \
    libc++abi-dev \
    libc6-dev

# Compiling
sudo apt install -y \
  clang \
  libclang-rt-dev \
  lld \
  lldb \
  llvm \
  ninja-build

# Tools
sudo apt install -y \
  clang-format \
  clang-tidy \
  clang-tools \
  clangd
```

Você pode **verificar** a instalação com os comandos abaixo.
As versões instaladas devem ser iguais ou superiores às listadas.

```zsh title="Mint" frame="terminal"
clang --version
# Ubuntu clang version 18.1.3 (1ubuntu1)
# Target: x86_64-pc-linux-gnu
# Thread model: posix
# InstalledDir: /usr/bin

ninja --version
# 1.11.1
```
