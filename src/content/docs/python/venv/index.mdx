Uma das características fundamentais do Python é a facilidade de que dispõe para instalar pacotes utilitários.
Para que diferentes projetos nos nossos computadores não tenham conflitos de versões, é recomendado criar um **ambiente virtual** para cada um.

Existem várias ferramentas que fazem isso.
Neste guia, usaremos o [**venv**](https://docs.python.org/3/library/venv.html).
Ele é um módulo padrão do Python, que cria uma pasta isolada dentro de um projeto.
Então, podemos usar o **pip** para instalar as dependências dentro dessa pasta.

## Criação de um projeto

**Crie** uma pasta dentro do diretório `python` chamada `colors`.

```zsh title="Fedora, WSL ou Mint" frame="terminal"
cd ~/dev/python
mkdir -p colors
cd colors
```

Então, **abra** o Visual Studio Code nessa pasta.

```zsh title="Fedora, WSL ou Mint" frame="terminal"
code .
```

**Ative** o perfil do Python que criamos dentro do VSCode.

Por dentro do VSCode, **crie** um arquivo chamado `main.py` e adicione o seguinte código.

```python title="main.py"
name = input('Qual é o seu nome? ')
print(f'Olá, {name}!')
```

Este é o mesmo código que usamos no [capítulo anterior](../run).
Execute-o por meio do painel lateral `Run and Debug`, como explicado anteriormente.

### Linha de comando

**Abra** no terminal a pasta que criamos.

```zsh title="Fedora, WSL ou Mint" frame="terminal"
cd ~/dev/python/colors
```

Então, **crie** um ambiente virtual com o `venv` usando o comando a seguir.

```zsh title="Fedora, WSL ou Mint" frame="terminal"
python -m venv .venv
```

Isso criará uma pasta no seu projeto com o nome `.venv`.

Agora, é necessário **ativar** o ambiente criado.
Para isso, execute o comando a seguir.

```zsh title="Fedora, WSL ou Mint" frame="terminal"
source .venv/bin/activate
```

Toda vez que você fechar e abrir o terminal nessa pasta, será necessário ativar o venv novamente por meio desse comando.

## Instalando um pacote

Vamos instalar o pacote [**`rich`**](https://rich.readthedocs.io/en/stable/introduction.html), que facilita colorir o texto impresso no terminal pelo nosso programa.

**Abra** o terminal na pasta do projeto.
Pode ser o terminal integrado do VSCode, ou então um terminal externo com o venv ativado.

Então, **execute** o comando de instalação a seguir.

```zsh title="Fedora, WSL ou Mint" frame="terminal"
pip install rich
```

## Gerenciando dependências

Quando lidamos com pacotes, queremos que pessoas que usam nossos projetos possam instalar as mesmas dependências nas mesmas versões.
Para garantir isso, podemos criar uma lista de pacotes instalados.

**Abra** o terminal na pasta do projeto com o venv ativado e **execute** o comando a seguir.

```zsh title="Fedora, WSL ou Mint" frame="terminal"
touch requirements.txt
```

Isso **cria** o arquivo em que listaremos os pacotes.

Agora, vamos verificar qual é a **versão** que instalamos do pacote `rich`.

**Execute** o comando a seguir para obter as informações do pacote.

```zsh title="Fedora, WSL ou Mint" frame="terminal"
pip show rich
```

```txt title="Fedora, WSL ou Mint" frame="terminal"
Name: rich
Version: 15.0.0
Summary: Render rich text, tables, progress bars, syntax highlighting, markdown and more to the terminal
Home-page: https://github.com/Textualize/rich
Author: Will McGugan
Author-email: willmcgugan@gmail.com
License: MIT
Location: /home/gabriel/dev/python/colors/.venv/lib64/python3.14/site-packages
Requires: markdown-it-py, pygments
Required-by:
```

Na data de escrita deste guia, o `rich` está na versão `15.0.0`.

**Edite** o arquivo `requirements.txt` para adicionar o pacote.
Podemos ignorar o último número de versão, pois ele tende a representar atualizações de pouco impacto na funcionalidade.
Ele deve ficar como a seguir.

```txt title="requirements.txt"
rich>=15.0
```

Se quiser instalar outros pacotes, você pode listá-los abaixo nesse mesmo arquivo.
Por exemplo, **adicione** uma linha para o pacote `cowsay`.

```txt title="requirements.txt" ins={2}
rich>=15.0
cowsay>=6.1
```

Para instalar os pacotes descritos nessa lista, **execute** o comando a seguir.

```zsh title="Fedora, WSL ou Mint" frame="terminal"
pip install -r requirements.txt
```

